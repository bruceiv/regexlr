# RegexLR Parser Generator

The intent of the RegexLR parser-generator is to combine the ease-of-use and unified semantics of scannerless parsing with the performance of a regex-tokenized LR parser.

## Status

This is a hobby project, and currently wildly incomplete; it does nothing of value at present.

## Contributing

Until such time as RegexLR reaches 0.1, it is a single-contributor project. 
Helpful contributions would be links to papers on the following or similar topics:
* regex-based LR items
* disambiguating LR parsers by longest match
* incorporating ordered-choice or operator-precedence parsing into the LR algorithm
